🔬 2. 툴(Tool) 사용 판단의 구체적 코드 근거
근거 1: 소수점 10자리 단위의 `vw` 변환 수치 (common.css 내 324개 이상 발견)

개발자가 직접 코딩을 진행할 경우 가독성과 유지보수를 위해 `1.04vw`처럼 소수점 2자리까지 정리하거나 `calc()`를 사용합니다. 그러나 소스코드 상에는 1920px 시안 기준 계산식 결과인 소수점 10자리 수치가 그대로 존재합니다.

/* 1920px 디자인 시안 픽셀값을 자동 변환기로 돌렸을 때 나오는 수치 예시 */ padding-left: 1.0416666667vw; /* = 20px / 1920px * 100 */ margin-top: 3.6458333333vw; /* = 70px / 1920px * 100 */ gap: 2.0833333333vw; /* = 40px / 1920px * 100 */ font-size: 0.5208333333vw; /* = 10px / 1920px * 100 */
근거 2: `module.css` (2.13MB, 30,000줄) 통째 덤프 및 과거 2022~2023년 주석 수천 개 방치

`module.css` 내부를 확인한 결과, 신규 작성한 스타일 외에 과거 SDS 이전 웹사이트(2022~2023년)에서 사용하던 CSS 모듈 소스가 툴로 통째 추출되어 2.13MB로 부풀려져 있습니다.

/* module.css 내부 실제 발견된 레거시 추출 주석 예시 */ /* 20221202 gnb기능 분기 */ /* 20230420 서브페이지 클라우드 였을때 bg 이미지 */ /* 20230518 gnb 호버시 스크롤바 너비 계산 */
⚠️ 3. 변경되지 않아도 되는데 변경된 불필요/부작용 항목 (Warning Points)
1) 보존되어야 할 레거시 파일(`report-detail_legacy.html`)의 잦은 수정

`report-detail_legacy.html`은 리뉴얼 전 레거시 참조용 파일임에도 불구하고, v260715, v260720, v260722_02 버전 업데이트 시마다 신규 헤더/푸터 HTML이 복사-붙여넣기되어 줄수가 1,793줄에서 3,806줄로 2배 이상 팽창되었습니다.

2) `common.css` 전체 1줄 Minify(압축)화로 인한 형상관리(Git) 불가능

`v260722` 버전에서 `common.css` (164KB)가 1줄로 통합 압축되며, `v260722_02` 버전에서 수정된 스타일의 정확한 Diff(추적)이 불가능해졌습니다. 유지보수 단계에서는 비압축 표준 개발용 CSS 형태를 유지해야 합니다.

3) 작업 잔재 파일 및 더미 가이드 생성/삭제 핑퐁

`contact/form copy.html`과 같은 사내 내부 작업용 복사본 파일이 최종 납품 폴더에 포함되어 있으며, `guide/etc.html` 등의 가이드 파일이 새로 만들어졌다가 일주일 만에 삭제되는 등 납품 폴더 정리가 미흡했습니다.
