## 🤖 1. 외주업체 자동화 툴(Tool) 사용 분석 결과

소스코드 전수 조사 결과, 외주업체가 100% 수작업으로 마크업을 개발한 것이 아니라 **Figma to Code 자동 변환 플러그인** 및 **PX-to-VW 자동 계산 빌드 툴**을 활용하여 시안에서 코드를 자동 추출한 후 기존 레거시 소스에 결합한 것으로 확정 판단됩니다.

### 🛠️ 사용된 추정 툴 / 플러그인 목록
1. **Figma PX to VW Auto Converter (또는 SCSS/PostCSS px2vw 빌드 메커니즘)**
   * Figma 시안의 픽셀(px) 단위를 responsive 웹용 `vw` 단위로 변환해 주는 자동 변환 툴
2. **Anima for Figma / Figma to HTML Exporter**
   * Figma 시안 레이아웃과 이펙트 애니메이션을 CSS 코드로 추출하는 툴
3. **CSS Minifier (PostCSS / CSSNano)**
   * `common.css`를 최신 버전에서 1줄로 강제 압축(Minify)한 툴

## 🔬 2. 툴(Tool) 사용 판단의 구체적 코드 근거

### 근거 1: 소수점 10자리에 달하는 극단적 `vw` 계산 수치 (`common.css` 내 324개 이상)
사람이 직접 CSS 코드를 작성할 경우 가독성과 반올림 정돈을 위해 `1.04vw` 또는 `calc()`를 사용합니다. 그러나 `common.css` 상에는 **1920px 시안 기준 픽셀 계산 결과식인 소수점 10자리 수치**가 그대로 노출되어 있습니다.

```css
/* common.css 내 실제 발견된 자동 변환기 추출 수치 예시 */
padding-left: 1.0416666667vw;   /* = 20px / 1920px * 100 */
margin-top: 3.6458333333vw;     /* = 70px / 1920px * 100 */
gap: 2.0833333333vw;            /* = 40px / 1920px * 100 */
font-size: 0.5208333333vw;      /* = 10px / 1920px * 100 */
```

### 근거 2: `module.css` (2.13MB, 30,000줄) 통째 덤프 및 과거 2022~2023년 주석 수천 개 방치
`module.css` 파일은 크기가 무려 **2.13MB(30,019줄)**에 달합니다. 내부 주석을 분석한 결과, 외주업체가 신규 퍼블리싱을 처음부터 한 것이 아니라 **이전 SDS 웹사이트(2022년~2023년 운영 소스)에서 추출 툴로 긁어온 legacy CSS 모듈을 검수 없이 통째 붙여넣은 흔적**이 명백히 나타납니다.

```css
/* module.css 내부 실제 발견된 레거시 방치 주석 예시 */
/* 20221202 gnb기능 분기 */
/* 20230420 서브페이지 클라우드 였을때 bg 이미지 */
/* 20230518 gnb 호버시 스크롤바 너비 계산 */
```

## ⚠️ 3. 변경되지 않아도 되는데 변경된 불필요/부작용 항목 (Warning Points)

### 1) 보존되어야 할 레거시 기준 파일(`report-detail_legacy.html`)의 잦은 수정
`report-detail_legacy.html`은 이름 그대로 **기존 레거시 뷰 보존/비교용 기준 파일**입니다. 그러나 외주업체에서 버전 업그레이드(`v260715`, `v260720`, `v260722_02`)를 진행하면서 신규 헤더/푸터 마크업을 레거시 파일에까지 계속 복사-붙여넣기하여, **파일 용량이 1,793줄에서 3,806줄로 2배 이상 팽창**되었습니다.

### 2) `common.css` 전체 1줄 Minify(압축)화로 인한 형상관리(Git Diff) 불가능
`v260722` 버전에서 `common.css` (164KB)가 갑자기 **전체 1줄로 한 줄 압축(Minified)** 처리되었습니다. 이로 인해 최신 버전(`v260722_02`)에서 정확히 어떤 CSS 속성이 수정되었는지 Git 코드 비교(Diff) 및 검수가 완전히 불가능해지는 부작용이 발생했습니다.

### 3) 불필요한 작업 복사본 파일 방치 (`contact/form copy.html`)
최종 전달 폴더 내에 `contact/form copy.html`과 같은 사내 작업용 복사본 파일이 정리되지 않은 채 남아 있습니다.

### 4) 더미 가이드 파일 생성 후 소멸 핑퐁
`v260715`에서 `guide/etc.html`, `guide/icon.html`, `guide/popup.html` 등을 신규 추가했다가 `v260720` 및 `v260722`에서 다시 삭제하는 등 납품 폴더 구성 관리가 정돈되지 않았습니다.
