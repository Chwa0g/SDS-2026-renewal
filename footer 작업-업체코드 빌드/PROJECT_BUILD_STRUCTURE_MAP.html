🗺️ 프로젝트 빌드 파일 1:1 & 1:N 대입 맵 가이드

Samsung SDS Renewal Project - 소스 파일 수정 시 어떤 빌드 파일(dist)로 변환되는지 직관적 매핑 정리

1. SCSS ➔ CSS 파일 빌드 대입 맵

app/static/scss/ 아래의 파티셜 파일(_*.scss)을 수정하면 해당 파일이 import된 엔트리 파일이 컴파일되어 dist/static/css/ 아래 생성됩니다.

내가 수정하는 SCSS 소스 파일 (app/) 빌드 시 출력되는 CSS 파일 (dist/) 영향 범위 및 설명
page/_layout.scss ➔ layout.css
common_renew.css		 [푸터, 헤더, 레이어 모달] 2개 CSS 파일에 동시 반영
page/_base.scss ➔ layout.css
common_renew.css		 [기본 폰트, 공통 리셋] 2개 CSS 파일에 동시 반영
page/_component.scss ➔ component.css
common_renew.css		 [버튼, 카드, 폼 요솔] 2개 CSS 파일에 동시 반영
page/_main.scss ➔ main.css
common_renew.css		 [메인 페이지 스타일] 2개 CSS 파일에 동시 반영
page/_insight.scss ➔ insight.css
common_renew.css		 [인사이트 페이지 스타일] 2개 CSS 파일에 동시 반영
page/_contact.scss ➔ contact.css
common_renew.css		 [문의하기 페이지 스타일] 2개 CSS 파일에 동시 반영
page/_offer.scss ➔ offering.css
common_renew.css		 [오퍼링 페이지 스타일] 2개 CSS 파일에 동시 반영
sub/_mixin.scss / _function.scss ➔ 모든 CSS 파일 전체 공통 계산식/믹스인이므로 전체 CSS에 적용

2. HTML & .inc 파일 빌드 대입 맵

내가 수정하는 소스 파일 (app/) 빌드 시 출력되는 최종 HTML 파일 (dist/) 영향 범위
app/inc/footer.inc ➔ dist/html/dashboard.html
dist/html/main.html
dist/html/**/*.html (전체)		 [푸터 & 레이어 모달 팝업]
모든 HTML 페이지의 푸터 위치에 실시간 주입 병합
app/inc/header.inc ➔ dist/html/**/*.html (전체) [상단 헤더 & GNB 메뉴] 모든 HTML 상단에 실시간 주입
app/html/dashboard.html ➔ dist/html/dashboard.html 단일 대시보드 페이지 (inc 주입 후 완성형 생성)

3. JavaScript & 자산 1:1 대입 맵

개발 소스 파일 (app/) 빌드 출력 파일 (dist/) 변환 방식
app/static/js/ui.js ➔ dist/static/js/ui.js 1:1 동기화 복사 (UI 스크립트 모듈)
app/static/images/**/* ➔ dist/static/images/**/* 1:1 동기화 복사 (이미지 전체)

4. 한눈에 보는 핵심 요약

■ [1. 푸터 텍스트/모달 팝업 추가/수정] - 수정 소스: app/inc/footer.inc - 최종 빌드: dist/html/*.html (모든 HTML 페이지에 실시간 합체 생성) ■ [2. 푸터 스타일/모달 디자인 수정] - 수정 소스: app/static/scss/page/_layout.scss - 최종 빌드: dist/static/css/layout.css + dist/static/css/common_renew.css (2개 CSS 파일에 동시 컴파일) ■ [3. 푸터 모달/아코디언 JS 기능 수정] - 수정 소스: app/static/js/ui.js - 최종 빌드: dist/static/js/ui.js (1:1 복사)
