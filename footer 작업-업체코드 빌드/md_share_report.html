md_share 공유하기 & printPost 인쇄 모듈화 보고서

md_share 팝업 모듈(HTML/SCSS/JS)의 전체 기능과 printPost() 인쇄 기능까지 모두 통합하여 작성한 종합 가이드 보고서입니다.

1. 개요 및 모듈화 성과

md_share 공유 팝업 모듈

  • 3개 모듈 추출: md_share.inc, _md_share.scss, md_share.js
  • WAI-ARIA 규격: role="dialog", 포커스 트랩(Tab 순환), ESC 닫기
  • 7종 SNS 지원: Linkedin, Facebook, X, KakaoTalk, Instagram, Naver, 링크 복사

printPost() 인쇄 기능 통합

  • 자유로운 연동: 클래스 제약 없이 onclick="return printPost();"로 연결
  • 이중 팝업 해결: 500ms 디바운스 Check 내장
  • 스타일 자동 원복: 페이지 리로드 없이 afterPrint() 시 요소 원복

③ JS 스크립트 모듈 (app/static/js/md_share.js)

app/static/js/md_share.js (md_pop_share04 & printPost)
// 1. 공유 팝업 열기
function md_pop_share04(btn) {
    var $btn = $(btn);
    var $target = $('#md_share_area');
    if (!$target.length) return false;

    var offset = $btn.offset();
    var wrapOffset = $('#wrap').offset() || { top: 0, left: 0 };
    var topPos = offset.top - wrapOffset.top + $btn.outerHeight() + 10;
    var leftPos = offset.left - wrapOffset.left;

    $target.find('.md_share_box').css({ top: topPos + 'px', left: leftPos + 'px' });
    $target.addClass('on');
    focusTrapOn($target);
    return false;
}

// 2. 게시글 인쇄 기능
var lastPrintTime = 0;
function printPost() {
    var now = new Date().getTime();
    if (now - lastPrintTime < 500) return false;
    lastPrintTime = now;

    window.onbeforeprint = beforePrint;
    window.onafterprint = afterPrint;
    window.print();
    return false;
}

function afterPrint() {
    $(".insight-report-detail__side, .insight-report-detail__share").css("display", "");
}

4. 페이지 연동 가이드

  • 공유하기 버튼 연동

  • 인쇄하기 버튼 연동
    <button type="button" class="insight-report-detail__share-button--print" onclick="return printPost();">인쇄하기</button>
