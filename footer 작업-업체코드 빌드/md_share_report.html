md_share 공유하기 팝업 모듈화 보고서

기존 운영 페이지의 분산된 공유 팝업 코드를 추출하여 HTML, SCSS, JS 표준 컴포넌트로 구축하고 하위 호환성 및 웹 접근성(WAI-ARIA)을 확보한 작업 문서입니다.

1. 개요 및 모듈화 목적

기존 이슈 분석

  • 이벤트 및 운영 페이지 전반에 HTML/CSS/JS가 파편화되어 존재
  • 중복 스크립트로 인한 이중 이벤트 호출 및 팝업 토글 오류
  • 웹 접근성(포커스 이동, ESC 닫기) 미지원 문제

모듈화 개선 성과

  • 3개 모듈 추출: md_share.inc, _md_share.scss, md_share.js
  • 100% 하위 호환성: 기존 `md_pop_share04` 함수 유지
  • WAI-ARIA 규격: 포커스 트랩(Tab 순환) 및 ESC 제어

② JavaScript 동작 모듈 (app/static/js/md_share.js)

app/static/js/md_share.js
// 글로벌 공유 팝업 호출 함수 (하위 호환성 100% 보장)
function md_pop_share04(btn) {
    var $btn = $(btn);
    var $target = $('#md_share_area');
    if (!$target.length) return false;

    // 이중 클릭 토글 디바운스 Check
    var lastTime = $target.data('last_share_click') || 0;
    var now = new Date().getTime();
    if (now - lastTime < 200) return false;
    $target.data('last_share_click', now);

    // #wrap 좌표 기준 팝업 위치 자동 산출
    var offset = $btn.offset();
    var wrapOffset = $('#wrap').offset() || { top: 0, left: 0 };
    var topPos = offset.top - wrapOffset.top + $btn.outerHeight() + 10;
    var leftPos = offset.left - wrapOffset.left;

    $target.find('.md_share_box').css({ top: topPos + 'px', left: leftPos + 'px' });
    $target.addClass('on');
    focusTrapOn($target);
    return false;
}

4. 페이지 연동 가이드

  • SSI HTML & Script Include

    페이지 푸터 위치 및 script.inc에 모듈을 포함합니다.

    <!--#include file="/inc/md_share.inc" -->
<script src="/static/js/md_share.js"></script>
  • 공유하기 버튼 onclick 이벤트 연동

    공유 버튼 요소에 onclick="return md_pop_share04(this);" 속성을 지정합니다.

    <button type="button" 
        class="insight-report-detail__share-button insight-report-detail__share-button--share" 
        onclick="return md_pop_share04(this);">
    공유하기
</button>
